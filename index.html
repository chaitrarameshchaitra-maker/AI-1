Top 8-Mark Guaranteed Derivations

1. Maxwell's 4th Equation & Displacement Current PHY101

Derive Ampere-Maxwell law starting from ∇ · J = -∂ρ/∂t.

Step 1: ∇ × B = μ₀ J (Ampere's original)
Step 2: Take divergence: ∇ · (∇ × B) = 0
Step 3: But ∇ · J = -∂ρ/∂t ≠ 0 (Contradiction!)
Step 4: Add displacement current: J_d = ε₀ ∂E/∂t
2. Star-Delta Transformation (3-Phase) BEE102

Equate terminal resistances between pairs (R_AB, R_BC, R_CA).

R_A = (R_AB × R_CA) / (R_AB + R_BC + R_CA)
R_B = (R_BC × R_AB) / (R_AB + R_BC + R_CA)
R_C = (R_CA × R_BC) / (R_AB + R_BC + R_CA)
